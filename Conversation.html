JFT / N5 စကားပြော သုံးစွဲပုံများ (၁-၁၀၀)

၁။ おはようございます (Ohayou gozaimasu) မင်္ဂလာနံနက်ခင်းပါ
ဥပမာ:
A: おはようございます。 A: မင်္ဂလာနံနက်ခင်းပါ။ B: おはようございます。今日もがんばりましょう。 B: မင်္ဂလာနံနက်ခင်းပါ။ ဒီနေ့လည်း ကြိုးစားကြတာပေါ့။
Kotoba Note: 今日 (きょう) = ဒီနေ့ がんばりましょう = ကြိုးစားကြစို့
၂။ はじめまして (Hajimemashite) တွေ့ရတာ ဝမ်းသာပါတယ် (ပထမဆုံးအကြိမ် တွေ့ဆုံချိန်)
ဥပမာ:
A: はじめまして、アウンです。 A: တွေ့ရတာ ဝမ်းသာပါတယ်၊ အောင် ပါ။ B: はじめまして、田中です。 B: တွေ့ရတာ ဝမ်းသာပါတယ်၊ တာနာကာ ပါ။
Kotoba Note: はじめまして = မိတ်ဆက်စကား စတင်ပြောဆိုရာတွင် သုံးသော အသုံးအနှုန်း
၃။ どうぞよろしくおねがいします (Douzo yoroshiku onegaishimasu) ကူညီစောင့်ရှောက်ပေးပါဦး
ဥပမာ:
A: 今日からここで働きます。どうぞよろしくお願いします。 A: ဒီနေ့ကစပြီး ဒီမှာ အလုပ်လုပ်မှာပါ။ ကူညီစောင့်ရှောက်ပေးပါဦး။ B: こちらこそ、よろしくお願いします。 B: ကျွန်တော်လည်း ကူညီစောင့်ရှောက်ပေးပါဦး။
Kotoba Note: 今日から (きょうから) = ဒီနေ့ကစပြီး 働きます (はたらきます) = အလုပ်လုပ်သည်
၄။ しつれいですが… (Shitsurei desu ga...) တစ်ဆိတ်လောက်ပါ... / အားနာပေမဲ့...
ဥပမာ:
A: 失礼ですが、お名前は？ A: တစ်ဆိတ်လောက်ပါ၊ နာမည်လေး ဘယ်လိုခေါ်ပါသလဲ။ B: マウンマウンです。 B: မောင်မောင် ပါ။
Kotoba Note: 失礼 (しつれい) = ရိုင်းပျခြင်း / အားနာစရာဖြစ်ခြင်း
၅။ すみませんが… (Sumimasen ga...) တစ်ဆိတ်လောက်ပါ... / အားနာပေမဲ့...
ဥပမာ:
A: すみませんが、これを教えてください。 A: တစ်ဆိတ်လောက်ပါ၊ ဒါလေး သင်ပေးပါဦး။ B: いいですよ。 B: ရပါတယ်လေ။
Kotoba Note: 教え (おしえ) ます = သင်ပေးသည် / ပြောပြသည်
၆။ おなまえは？ (Onamae wa?) နာမည် ဘယ်လိုခေါ်ပါသလဲ။
ဥပမာ:
A: お名前は？ A: နာမည် ဘယ်လိုခေါ်ပါသလဲ။ B: スースーです。 B: ဆူဆူ ပါ။
Kotoba Note: お名前 (おなまえ) = နာမည် (ယဉ်ကျေးသော အသုံး)
၇။ こんにちは (Konnichiwa) မင်္ဂလာပါ (နေ့လယ်ခင်း နုတ်ဆက်စကား)
ဥပမာ:
A: こんにちは、山田さん。 A: မင်္ဂလာပါ ယမဒါဆန်။ B: こんにちは。良い天気ですね。 B: မင်္ဂလာပါ။ ရာသီဥတု ကောင်းတယ်နော်။
Kotoba Note: 良い (いい / よい) = ကောင်းသော 天気 (てんき) = ရာသီဥတု
၈။ はい、そうです (Hai, sou desu) ဟုတ်တယ်၊ အဲ့လိုပါ။
ဥပမာ:
A: あなたは学生ですか。 A: သင်က ကျောင်းသားလား။ B: はい、そうです。 B: ဟုတ်ပါတယ်၊ ကျောင်းသားပါ။
Kotoba Note: 学生 (がくせい) = ကျောင်းသား/သူ
၉။ いいえ、ちがいます (Iie, chigaimasu) မဟုတ်ပါဘူး၊ လွဲနေပါတယ်။
ဥပမာ:
A: これは田中さんの本ですか。 A: ဒါက တာနာကာဆန်ရဲ့ စာအုပ်လား။ B: いいえ、違います。 B: မဟုတ်ပါဘူး၊ မှားနေပါတယ်။
Kotoba Note: 本 (ほん) = စာအုပ် 違います (ちがいます) = မတူပါ / မဟုတ်ပါ
၁၀။ これからお世話になります (Kore kara osewa ni narimasu) အခုကစပြီး ကူညီစောင့်ရှောက်ပေးပါဦး။
ဥပမာ:
A: 新しいスタッフのキムです。これからお世話になります。 A: ဝန်ထမ်းသစ် ကင်မ် ပါ။ အခုကစပြီး ကူညီစောင့်ရှောက်ပေးပါဦး။ B: よろしくお願いします。 B: ကူညီစောင့်ရှောက်ပေးပါဦး။
Kotoba Note: 新しい (あたらしい) = သစ်သော お世話 (おせわ) = အကူအညီ / စောင့်ရှောက်မှု
၁၁။ あのう～ (Anou...) ဟိုလေ... (စကားစတင်ပြောရန် တုံ့ဆိုင်းချိန်သုံး)
ဥပမာ:
A: あのう、ペンを借りてもいいですか。 A: ဟိုလေ... ဘောပင် ခဏငှားလို့ ရမလား။ B: はい、どうぞ。 B: ဟုတ်ကဲ့၊ ယူပါ။
Kotoba Note: 借ります (かります) = ငှားသည်
၁၂။ どうぞ (Douzo) ယူပါ / ဖိတ်ခေါ်ပါတယ်
ဥပမာ:
A: 入ってもいいですか。 A: ဝင်လို့ရမလား။ B: はい、どうぞ。 B: ဟုတ်ကဲ့၊ ဝင်ပါ။
Kotoba Note: 入ります (はいります) = ဝင်သည်
၁၃။ これは何ですか (Kore wa nan desu ka) ဒါက ဘာလဲ။
ဥပမာ:
A: これは何ですか。 A: ဒါက ဘာလဲ။ B: これは日本の和菓子です。 B: ဒါက ဂျပန်ရိုးရာ မုန့်ပါ။
Kotoba Note: これ = ဒါ / ဤအရာ 何 (なん/なに) = ဘာလဲ
၁၄။ ありがとうございます (Arigatou gozaimasu) ကျေးဇူးတင်ပါတယ်။
ဥပမာ:
A: お茶をどうぞ。 A: ရေနွေးကြမ်း သောက်ပါဦး။ B: ありがとうございます。 B: ကျေးဇူးတင်ပါတယ်။
Kotoba Note: お茶 (おちゃ) = ရေနွေးကြမ်း / လက်ဖက်ရည်
၁၅။ どうもありがとうございます (Doumo arigatou gozaimasu) ကျေးဇူးအထူးတင်ပါတယ်။
ဥပမာ:
A: 手伝いましょうか。 A: ကူညီပေးရမလား။ B: どうもありがとうございます。 B: ကျေးဇူးအထူးတင်ပါတယ်။
Kotoba Note: 手伝います (てつだいます) = ကူညီသည်
၁၆။ いくらですか (Ikura desu ka) ဘယ်လောက်ပါလဲ။ (စျေးနှုန်းမေးမြန်းခြင်း)
ဥပမာ:
A: このリンゴはいくらですか。 A: ဒီပန်းသီးက ဘယ်လောက်ပါလဲ။ B: 100円です。 B: ယန်း ၁၀၀ ပါ။
Kotoba Note: リンゴ = ပန်းသီး 円 (えん) = ယန်း (ဂျပန်ငွေကြေး)
၁၇။ これをください (Kore o kudasai) ဒါလေး ပေးပါ။ (ဝယ်ယူသည့်အခါ သုံးသည်)
ဥပမာ:
A: これをください。 A: ဒါလေး ပေးပါ။ B: はい、かしこまりました。 B: ဟုတ်ကဲ့၊ ကောင်းပါပြီ။
Kotoba Note: ください = ပေးပါ
၁၈။ いらっしゃいませ (Irasshaimase) ဆိုင်မှ ကြိုဆိုပါတယ်
ဥပမာ:
店員: いらっしゃいませ！ ဆိုင်ဝန်ထမ်း: ဆိုင်မှ ကြိုဆိုပါတယ်ခင်ဗျာ/ရှင့်။ 客: こんにちは。 ဧည့်သည်: မင်္ဂလာပါ။
Kotoba Note: 店員 (てんいん) = ဆိုင်ဝန်ထမ်း 客 (きゃく) = ဧည့်သည် / ဈေးဝယ်သူ
၁၉။ すみません (Sumimasen) တစ်ဆိတ်လောက် / တောင်းပန်ပါတယ်။
ဥပမာ:
A: すみません、駅はどこですか。 A: တစ်ဆိတ်လောက်ပါ၊ ရထားဘူတာက ဘယ်မှာလဲ။ B: あそこです。 B: ဟိုမှာပါ။
Kotoba Note: 駅 (えき) = ရထားဘူတာ どこ = ဘယ်မှာလဲ
၂၀။ どうも (Doumo) ကျေးဇူးပါ / အင်းပါ
ဥပမာ:
A: ドアを開けましたよ。 A: တံခါး ဖွင့်ပေးထားတယ်နော်။ B: どうも。 B: ကျေးဇူးပါ။
Kotoba Note: ドア = တံခါး 開けます (あけます) = ဖွင့်သည်
၂၁။ なんばんですか (Nanban desu ka) နံပါတ် ဘယ်လောက်လဲ။
ဥပမာ:
A: 電話番号は何番ですか。 A: ဖုန်းနံပါတ် ဘယ်လောက်လဲ။ B: 090-1234-5678です。 B: ၀၉၀-၁၂၃၄-၅၆၇၈ ပါ။
Kotoba Note: 電話番号 (でんわばんごう) = ဖုန်းနံပါတ်
၂၂။ そうですか (Sou desu ka) ဟုတ်လား / အဲ့လိုလား။
ဥပမာ:
A: 明日は休みですよ。 A: မနက်ဖြန်က ပိတ်ရက်လေ။ B: そうですか。知りませんでした。 B: ဟုတ်လား၊ မသိခဲ့ဘူး။
Kotoba Note: 明日 (あした) = မနက်ဖြန် 休み (やすみ) = ကျောင်း/အလုပ် ပိတ်ရက်
၂၃။ たいへんですね (Taihen desu ne) ပင်ပန်းမှာပဲနော် / ခက်ခဲမှာပဲနော်
ဥပမာ:
A: 毎日10時間働きます。 A: နေ့တိုင်း ၁၀ နာရီ အလုပ်လုပ်ပါတယ်။ B: 大変ですね。 B: ပင်ပန်းမှာပဲနော်။
Kotoba Note: 毎日 (まいにち) = နေ့တိုင်း 時間 (じかん) = နာရီ (ကြာချိန်)
၂၄။ いつですか (Itsu desu ka) ဘယ်အချိန်လဲ / ဘယ်တော့လဲ။
ဥပမာ:
A: テストはいつですか。 A: စာမေးပွဲက ဘယ်တော့လဲ။ B: 来週の月曜日です。 B: နောက်တစ်ပတ် တနင်္လာနေ့ပါ။
Kotoba Note: テスト = စာမေးပွဲ 来週 (らいしゅう) = နောက်တစ်ပတ်
၂၅။ どういたしまして (Dou itashimashite) ရပါတယ် / ကိစ္စမရှိပါဘူး (ကျေးဇူးတင်ကြောင်း ပြန်ပြောသည့်အခါ)
ဥပမာ:
A: ありがとうございます。 A: ကျေးဇူးတင်ပါတယ်။ B: どういたしまして。 B: ရပါတယ်၊ ကိစ္စမရှိပါဘူး။
Kotoba Note: —
၂၆။ そうですね (Sou desu ne) ဟုတ်တယ်နော် / အင်း...
ဥပမာ:
A: 今日は暑いですね。 A: ဒီနေ့ ပူတယ်နော်။ B: そうですね。 B: ဟုတ်တယ်နော်။
Kotoba Note: 暑い (あつい) = ပူသော (ရာသီဥတု)
၂၇။ どうもありがとうございました (Doumo arigatou gozaimashita) ကျေးဇူးအများကြီး တင်ခဲ့ပါတယ်။ (ပြီးစီးသွားသော အကူအညီအတွက်)
ဥပမာ:
A: 親切に教えてくれて、どうもありがとうございました。 A: ဖော်ဖော်ရွေရွေ ပြောပြပေးလို့ ကျေးဇူးအများကြီး တင်ခဲ့ပါတယ်။ B: いいえ、どういたしまして。 B: ရပါတယ်၊ ကိစ္စမရှိပါဘူး။
Kotoba Note: 親切 (しんせつ) = ကြင်နာသော / ဖော်ရွေသော
၂၈။ やすみましょう (Yasumimashou) နားကြစို့။
ဥပမာ:
A: 少し疲れましたね。 A: နည်းနည်း ပင်ပန်းသွားပြီနော်။ B: じゃあ、少し休みましょう。 B: ဒါဆို နည်းနည်း နားကြစို့။
Kotoba Note: 少し (すこし) = နည်းနည်း 疲れます (つかれます) = ပင်ပန်းသည်
၂၉။ わかりました (Wakarimashita) နားလည်ပါပြီ / သဘောပေါက်ပါပြီ။
ဥပမာ:
A: 9時に集合してください。 A: ၉ နာရီမှာ စုစည်းပေးပါ။ B: はい、わかりました。 B: ဟုတ်ကဲ့၊ နားလည်ပါပြီ။
Kotoba Note: 集合します (しゅうごうします) = လူစုစုဝေးဝေးလုပ်သည်
၃၀။ いっしょにいきませんか (Issho ni ikimasen ka) အတူတူ သွားကြမလား။
ဥပမာ:
A: 昼ご飯、一緒に行きませんか。 A: နေ့လယ်စာ အတူတူ သွားစားကြမလား။ B: いいですね。行きましょう。 B: ကောင်းတာပေါ့၊ သွားကြစို့။
Kotoba Note: 昼ご飯 (ひるごはん) = နေ့လယ်စာ 一緒に (いっしょに) = အတူတူ
၃၁။ また あした (Mata ashita) မနက်ဖြန်မှ တွေ့ကြစို့။
ဥပမာ:
A: 今日はお疲れ様でした。 A: ဒီနေ့အတွက် ပင်ပန်းသွားပါပြီ။ B: お疲れ様でした。また明日！ B: ပင်ပန်းသွားပါပြီ၊ မနက်ဖြန်မှ တွေ့ကြစို့။
Kotoba Note: お疲れ様 (おつかれさま) = ပင်ပန်းသွားပါပြီ (အလုပ်ခွင်သုံး)
၃၂။ いいですね (Ii desu ne) ကောင်းတာပေါ့ / သဘောတူတယ်နော်။
ဥပမာ:
A: 明日、映画を見に行きませんか。 A: မနက်ဖြန် ရုပ်ရှင်သွားကြည့်မလား။ B: いいですね！行きましょう。 B: ကောင်းတာပေါ့၊ သွားကြစို့။
Kotoba Note: 映画 (えいが) = ရုပ်ရှင်
၃၃။ なんですか (Nan desu ka) ဘာလဲ / ဘာဖြစ်လို့လဲ။
