JFT A2 文法ノート (Grammar Note)

အခန်းအလိုက် ရှင်းလင်းချက် + ဥပမာ + ဝေါဟာရမှတ်စု

第1課 先週、日本に来たばかりです (လွန်ခဲ့တဲ့အပတ်ကမှ ဂျပန်ကို ရောက်ခါစဖြစ်ပါတယ်)
❶ N1 という N2
ရှင်းလင်းချက်: N2 လို့ခေါ်သော N1 (အမည် သို့မဟုတ် အမျိုးအစားကို ဖော်ပြရာတွင် သုံးသည်)။
例: ホアは「花」という意味です။
(ဟိုအာ ဆိုတာ "ပန်း" လို့ခေါ်တဲ့ အဓိပ္ပာယ်ဖြစ်ပါတယ်။)
📝 Kodoba Note:
• 花 (はな - ဟာန) = ပန်း • 意味 (いみ - အိမိ) = အဓိပ္ပာယ်
❷ V-たばかりです
ရှင်းလင်းချက်: ကြိယာ၏ Verb-た (Past Form) + ばかりです။ ကိစ္စတစ်ခုကို ပြုလုပ်ပြီးခါစ၊ ပြီးစီးခဲ့သည်မှာ မကြာသေးမီကမှ ဖြစ်ကြောင်း ဖော်ပြသည်။
例: 先週、日本に来たばかりです။
(လွန်ခဲ့တဲ့အပတ်ကမှ ဂျပန်ကို ရောက်ခါစဖြစ်ပါတယ်။)
📝 Kodoba Note:
• 先週 (せんしゅう - ဆဲန်ရှူး) = လွန်ခဲ့သောအပတ် • 日本 (にほん - နိဟွန်း) = ဂျပန် • 来た (きた - ခိတ) = လာခဲ့သည် (来る ရဲ့ Past Form)
❸ V-ていました
ရှင်းလင်းချက်: Verb-て Form + いました။ အတိတ်က အချိန်အတိုင်းအတာတစ်ခုအထိ အလေ့အထအနေဖြင့် ပြုလုပ်ခဲ့ဖူးသည်/လုပ်ကိုင်နေခဲ့သည်ကို ဖော်ပြသည်။
例: ベトナムでは、ホテルで働いていました။
(ဗီယက်နမ်မှာတော့ ဟိုတယ်မှာ အလုပ်လုပ်ခဲ့ပါတယ်။)
📝 Kodoba Note:
• ベトナム (ဗီယက်နမ်) = ဗီယက်နမ် • ホテル (ဟိုထဲရု) = ဟိုတယ် • 働く (はたらく - ဟာတာရာခူ) = အလုပ်လုပ်သည်
❹ それ / そこ ＜文脈指示＞
ရှင်းလင်းချက်: စကားပြောဆိုမှု သို့မဟုတ် စာကြောင်းအဆက်အစပ်အတွင်း ရှေ့ကပြောခဲ့ပြီးသော အကြောင်းအရာ/နေရာကို ပြန်ညွှန်းခြင်း။
例: ジャワ島に、ジョグジャカルタという大きい町があります。ウォノソボは、そこから、バスで４時間ぐらいです။
(ဂျားဗားကျွန်းမှာ ဂျော့ဂျာကားတာဆိုတဲ့ မြို့ကြီးရှိပါတယ်။ ဝိုနိုဆိုဘိုကတော့ အဲဒီကနေ ဘတ်စ်ကားနဲ့ ၄ နာရီလောက် ကြာပါတယ်။)
📝 Kodoba Note:
• 大きい (おおきい - အိုးခီး) = ကြီးသော • 町 (まち - မာချိ) = မြို့ • バス (ဘာဆု) = ဘတ်စ်ကား • 時間 (じかん - ဂျိခန်) = နာရီ
❺ 〜て、〜 / 〜から、〜 / 〜けど、〜
ရှင်းလင်းချက်:
• 〜て: အကြောင်းအရာများကို ဆက်စပ်ဖော်ပြခြင်း
• 〜から: အကြောင်းပြချက် ဖော်ပြခြင်း (〜ကြောင့်)
• 〜けど: ဆန့်ကျင်ဘက် အကြောင်းအရာကို ဆက်စပ်ခြင်း (〜သော်လည်း / ပေမဲ့)
例①: お茶の畑がたくさんあって、のんびりしています။
(လက်ဖက်စိုက်ခင်းတွေ အများကြီးရှိပြီး အေးအေးဆေးဆေး ရှိလှပါတယ်။)
例②: ウランバートルは首都だから、都会ですよ။
(ဥလန်ဘာတာက မြို့တော်ဖြစ်လို့ စည်ကားတဲ့မြို့ကြီးပါပဲ။)
例③: 首都ではないけど、とてもにぎやかです။
(မြို့တော်တော့ မဟုတ်ပေမဲ့ သိပ်ကို စည်ကားပါတယ်။)
📝 Kodoba Note:
• お茶 (おちゃ - အိုချာ) = လက်ဖက်ရည်/ရေနွေးကြမ်း • 畑 (はたけ - ဟာတာခဲ) = စိုက်ခင်း • 首都 (しゅと - ရှုတို) = မြို့တော် • 都会 (とかい - တိုခိုအိ) = မြို့ကြီးပြကြီး • にぎやか (နိဂိယာခ) = စည်ကားသော
第2課 まじめそうな人ですね (ကြိုးစားအားထုတ်ပုံရတဲ့ လူနော်)
❶ N1 は N2 が ナA-です / イA-いです
ရှင်းလင်းချက်: N1 ၏ လက္ခဏာ သို့မဟုတ် စိတ်ကြိုက်ဖြစ်မှုကို N2 အကူအညီဖြင့် ဖော်ပြခြင်း (ဥပမာ- ဆံပင်ရှည်သည်၊ ရုပ်ချောသည်)။
例: 江口さんは、髪が短いです။
(အဲဂုချိစံက ဆံပင်တိုပါတယ်။)
📝 Kodoba Note:
• 髪 (かみ - ခါမိ) = ဆံပင် • 短い (みじかい - မိဂျိခါအိ) = တိုသော
❷ V-ている ＋ 人
ရှင်းလင်းချက်: ကြိယာ Verb-ている Form ဖြင့် လူ သို့မဟုတ် အရာဝတ္ထုကို ဝိသေသနပြု ညွှန်းဆိုခြင်း (ဥပမာ- ဦးထုပ်ဆောင်းထားသောလူ)။
例①: ナインさんは、帽子をかぶっている人です။
(နိုင်းစံက ဦးထုပ်ဆောင်းထားတဲ့ လူဖြစ်ပါတယ်။)
例②: 加藤さんは、あそこで、コピーをしている人です။
(ခါတိုးစံက ဟိုမှာ မိတ္တူကူးနေတဲ့ လူဖြစ်ပါတယ်။)
📝 Kodoba Note:
• 帽子 (ぼうし - ဗိုးရှိ) = ဦးထုပ် • かぶる (ခါဗုရု) = (ဦးထုပ်) ဆောင်းသည် • コピー (ခိုပီး) = မိတ္တူ
❸ Sよ
ရှင်းလင်းချက်: စာကြောင်းအဆုံးတွင် よ ထည့်၍ နားထောင်သူ မသိသေးသော အချက်အလက်ကို သတင်းပေးပြောဆိုခြင်း။
例: 原さんは、座って、本を読んでいる人ですよ။
(ဟာရာစံက ထိုင်ပြီး စာအုပ်ဖတ်နေတဲ့ လူပါနော်။)
📝 Kodoba Note:
• 座る (すわる - ဆုဝါရု) = ထိုင်သည် • 本 (ほん - ဟွန်း) = စာအုပ် • 読む (よむ - ယောမု) = ဖတ်သည်
❹ Sし、〜
ရှင်းလင်းချက်: အကြောင်းပြချက် သို့မဟုတ် လက္ခဏာတစ်ခုထက်မက အစဉ်လိုက် ဖော်ပြဆက်စပ်ခြင်း (〜လည်းဖြစ်ပြ၊ 〜လည်းဖြစ်သည်)။
例: 三船敏郎は、演技が上手いし、本当にかっこいいです။
(မိဖုနဲ တိုရှိရောက သရုပ်ဆောင်လည်း တော်သလို တကယ်ကို စမတ်ကျကျ ကြည့်ကောင်းပါတယ်။)
📝 Kodoba Note:
• 演技 (えんぎ - အဲန်ဂိ) = သရုပ်ဆောင်မှု • 上手い (うまい - ဥမိုင်း) = တော်သော/ကျွမ်းကျင်သော • 本当に (ほんとうに - ဟွန်းတိုးနိ) = တကယ်ကို • かっこいい (ခါခိုးအီး) = စမတ်ကျသော/ကြည့်ကောင်းသော
第3課 アレルギーがあるので、食べられないんです (ဓာတ်မတည့်တာရှိလို့ မစားနိုင်လို့ပါ)
❶ S1 ので、S2
ရှင်းလင်းချက်: ので ဖြင့် အကြောင်းပြချက်ကို ယဉ်ကျေးစွာ ဖော်ပြခြင်း (〜သောကြောင့် / မို့လို့)။
例: 今日は自転車で来たので、飲めないんです။
(ဒီနေ့ စက်ဘီးနဲ့လာတာမို့လို့ မသောက်နိုင်တာပါ/မသောက်တော့ပါဘူး။)
📝 Kodoba Note:
• 今日 (きょう - ခယိုး) = ဒီနေ့ • 自転車 (じてんしゃ - ဂျိတဲန်ရှာ) = စက်ဘီး • 飲む (のむ - နောမု) → 飲める (မသောက်နိုင်သည်)
❷ Sよね
ရှင်းလင်းချက်: နားထောင်သူ၏ သဘောတူညီချက်ကို တောင်းခံခြင်း သို့မဟုတ် အတည်ပြုမေးမြန်းခြင်း (〜နော် / မဟုတ်ဖူးလား)။
例: おすし、わさび、入ってますよね။
(အိုဆူရှီထဲမှာ ဝါဆာဗီ ပါတယ်နော်။)
📝 Kodoba Note:
• すし (ဆုရှိ) = ဆူရှီ • わさび (ဝါဆာဗီ) = ဝါဆာဗီ • 入る (はいる - ဟာအိရု) = ပါဝင်သည်/ဝင်သည်
❸ Nで〜
ရှင်းလင်းချက်: အခြေအနေ၊ နေရာ သို့မဟုတ် ရွေးချယ်မှုအဖြစ် で ကို အသုံးပြုခြင်း။
A: テーブルと座敷がございますが…။
(စားပွဲခုံနဲ့ ဂျပန်စတိုင် ထိုင်ခုံနေရာ ရှိပါတယ်ခင်ဗျာ...)
B: テーブルでお願いします။
(စားပွဲခုံနဲ့ပဲ မေတ္တာရပ်ခံပါရစေ/ပေးပါ။)
📝 Kodoba Note:
• テーブル (ထေဗုရု) = စားပွဲခုံ • 座敷 (ざしき - ဇာရှိခိ) = ဂျပန်စတိုင် ဖျာခင်းထားသော ထိုင်ခုံခန်း • お願いします (おねがいします - အိုနဲဂါအိရှိမဆု) = ကျေးဇူးပြု၍ မေတ္တာရပ်ခံပါသည်
❹ ナA-な / イA-い / V-る のは、Nです
ရှင်းလင်းချက်: のは ကိုသုံးပြီး ကြိယာ သို့မဟုတ် ဝိသေသနကို နာမ်ပြောင်း၍ ဗဟိုပြုပြောဆိုခြင်း (〜တာကတော့ N ဖြစ်ပါတယ်)။
例: 人気があるのは、お刺身定食です။
(လူကြိုက်များတာကတော့ အဆာရှိမိ ထမင်းချိုင့်/စုံတွဲပွဲ ဖြစ်ပါတယ်။)
📝 Kodoba Note:
• 人気 (にんき - နင်းခိ) = လူကြိုက်များခြင်း/ရေပန်းစားခြင်း • 刺身 (さしみ - ဆာရှိမိ) = အစိမ်းလတ်လတ်ဆတ်ဆတ် ငါးပါးပါးလှီး • 定食 (ていしょく - တေးရှော့ခု) = Set Menu / ထမင်းစုံတွဲပွဲ
第4課 しょうゆをつけないで食べてください (ပဲငံပြာရည် မဆို့ဘဲ စားပါ)
❶ Nなら、〜
ရှင်းလင်းချက်: တစ်ဖက်လူပြောလိုက်သော နာမ် (N) ကို အခြေခံ၍ အကြံပြုခြင်း သို့မဟုတ် စကားလမ်းကြောင်း စကားစဆက်ခြင်း (N ဆိုရင်တော့〜)။
A: この近くに、おすすめの店がありますか？
(ဒီအနီးအနားမှာ အကြံပြုချင်တဲ့ ဆိုင်ရှိပါသလား။)
B: この近くなら、「平兵衛」がお勧めです။
(ဒီအနီးအနားမှာဆိုရင်တော့ "ဟဲအိဗေ" ကို အကြံပြုချင်ပါတယ်။)
📝 Kodoba Note:
• 近く (ちかく - ချိခါခု) = အနီးအနား • おすすめ (အိုဆုဆုမဲ) = အကြံပြုချက်/ညွှန်းဆိုချက် • 店 (みせ - မိဆဲ) = ဆိုင်
❷ V-て、〜 ＜方法＞ / V-ないで、〜
ရှင်းလင်းချက်: ပြုလုပ်ဆောင်ရွက်သည့် နည်းလမ်း/ပုံစံ ကို ဖော်ပြခြင်း။
• V-て: လုပ်ဆောင်မှုတစ်ခုကို ပြုလုပ်လျက်...
• V-ないで: လုပ်ဆောင်မှုတစ်ခုကို မပြုလုပ်ဘဲ...
例①: こちらの野菜の天ぷらは、つゆにつけて食べてください။
(ဒီဘက်က အသီးအရွက် တန်ပူရာကို အရည်စိမ်ဆော့စ်နဲ့ ဆို့ပြီး စားပါ။)
例②: エビはつゆにつけないで、塩をかけて食べてください။
(ပုစွန်ကိုတော့ အရည်စိမ်ဆော့စ် မဆို့ဘဲ ဆားဖြူးပြီး စားပါ။)
📝 Kodoba Note:
• 野菜 (やさい - ယာဆိုင်း) = အသီးအရွက် • 天ぷらは (てんぷら - တဲန်ပူရာ) = တန်ပူရာ (ကြော်) • 塩 (しお - ရှီအို) = ဆား
❸ V-ちゃだめです
ရှင်းလင်းချက်: Verb-てはいけません ၏ စကားပြောစတိုင်ဖြစ်ပြီး မပြုလုပ်ရန် တားမြစ်ခြင်း (လုပ်လို့ မရဘူး/မလုပ်ရဘူး)။
例: 一度に、そんなにたくさんお肉を入れちゃだめですよ။
(တစ်ခါတည်းနဲ့ အဲဒီလောက် အသားအများကြီး ထည့်လို့မရဘူးနော်။)
📝 Kodoba Note:
• 一度に (いちどに - အိချိဒိုနိ) = တစ်ခါတည်းနဲ့ • 肉 (にく - နိခု) = အသား • 入れる (いれる - အိရဲရု) = ထည့်သည်
❹ V-てから、〜
ရှင်းလင်းချက်: Verb-て Form + から ။ ပြုလုပ်ဆောင်ရွက်မှုတစ်ခု ပြီးစီးသွားပြီးမှ နောက်တစ်ခုကို ပြုလုပ်ခြင်း (လုပ်ပြီးမှ〜)။
例: うどんは、お肉と野菜を食べてから、入れましょう။
(ဥဒေါင်းခေါက်ဆွဲကိုတော့ အသားနဲ့ အသီးအရွက်တွေကို စားပြီးမှ ထည့်ကြရအောင်။)
📝 Kodoba Note:
• うどん (ဥဒေါင်း) = ဂျပန်ဥဒေါင်းခေါက်ဆွဲ • 食べる (たべる - တာဗဲရု) = စားသည်
❺ S1 が、S2
ရှင်းလင်းချက်: စာကြောင်းနှစ်ခုကို が (သို့သော်/ ပေမဲ့) ဖြင့် ဆန့်ကျင်ဘက် ဆက်စပ်ပေးခြင်း။
例: お店は新しくてきれいですが、お昼は混んでいます။
(ဆိုင်က သစ်ပြီး သန့်ရှင်းပေမဲ့ နေ့လယ်ဘက်ဆို လူကြပ်/စည်ကားပါတယ်။)
📝 Kodoba Note:
• 新しい (あたらしい - အာတာရာရှီး) = သစ်သော • きれい (ခိရဲအိ) = လှပသော/သန့်ရှင်းသော • お昼 (おひる - အိုဟိရု) = နေ့လယ်ဘက် • 混む (こむ - ခိုမု) = လူကြပ်သည်
第5課 早く予約したほうがいいですよ (စောစောကြိုတင်ဘိုကင်လုပ်ထားတာ ပိုကောင်းပါလိမ့်မယ်)
❶ V-(られ)ます ＜可能形①＞
ရှင်းလင်းချက်: Potential Form (စွမ်းဆောင်နိုင်ရည်/ပြုလုပ်နိုင်စွမ်း) ကို ဖော်ပြခြင်း (လုပ်နိုင်သည်)။
例: 新鮮なカニとかウニとか食べられますよ။
(လတ်ဆတ်တဲ့ ဂဏန်းတို့ ကင်းမွန်တို့ စားနိုင်ပါတယ်နော်။)
📝 Kodoba Note:
• 新鮮 (しんせん - ရှိန်ဆဲန်) = လတ်ဆတ်သော • カニ (ခါနိ) = ဂဏန်း • ウニ (ဥနိ) = ပင်လယ်ဖြူကောင်/အူနီ
❷ 〜ところ
ရှင်းလင်းချက်: နေရာ သို့မဟုတ် အကြောင်းအရာကို ညွှန်းဆိုခြင်း (နေရာ/အချက်)။
例: 遊べるところはありますか？
(လည်ပတ်ဆော့ကစားလို့ရတဲ့ နေရာ ရှိပါသလား။)
📝 Kodoba Note:
• 遊ぶ (あそぶ - အာဆိုဗု) = ကစားသည်/လည်ပတ်သည်
❸ S(普通形) って聞きました / S(普通形) って言っていました
ရှင်းလင်းချက်: စကားပြောစတိုင်ဖြစ်ပြီး သတင်းအချက်အလက်ကို ပုဂ္ဂိုလ်တစ်ယောက်ထံမှ ကြားသိခဲ့ကြောင်း သို့မဟုတ် ပြောခဲ့ကြောင်း ပြန်လည်ပြောပြခြင်း။
例①: うどんがおいしいって聞きました။
(ဥဒေါင်းခေါက်ဆွဲ အရသာရှိတယ်လို့ ကြားသိခဲ့ရပါတယ်။)
例②: バスが安くて便利だって先輩が言っていました။
(ဘတ်စ်ကားက ဈေးသက်သာပြီး အဆင်ပြေတယ်လို့ စီနီယာက ပြောခဲ့ပါတယ်။)
📝 Kodoba Note:
• 安い (やすい - ယိုဆုအိ) = ဈေးသက်သာသော • 便利 (べんり - ဗဲန်ရိ) = အဆင်ပြေသော • 先輩 (せんぱい - ဆဲန်ပိုးအိ) = စီနီယာ/အကြီးတန်း
❹ 【疑問詞】V-たらいいですか？
ရှင်းလင်းချက်: အမေးစကားလုံး + V-たらいいですか ဖြင့် အကြံဉာဏ်တောင်းခံခြင်း (ဘယ်လို/ဘယ်သွား... လုပ်ရင် ကောင်းမလဲ)။
例: 日光に行くんですけど、何で行ったらいいですか？
(နိခိုးကို သွားမလို့ပါ၊ ဘာနဲ့သွားရင် ကောင်းမလဲခင်ဗျာ။)
📝 Kodoba Note:
• 日光 (にっこう - နိခိုး) = နိခိုး (ဂျပန်ရှိ ခေတ်ဟောင်းမြို့) • 行く (いく - အိခု) = သွားသည်
❺ V-たほうがいいです / V-ないほうがいいです
ရှင်းလင်းချက်: တစ်ဖက်လူကို အကြံဉာဏ် ပေးသည့်အခါ သုံးသည် (လုပ်တာ ပိုကောင်းတယ် / မလုပ်တာ ပိုကောင်းတယ်)။
例①: 厚い上着を持っていったほうがいいですよ။
(အထူ အပေါ်အင်္ကျီ ယူသွားတာ ပိုကောင်းပါလိမ့်မယ်။)
例②: できれば、日曜日は行かないほうがいいですよ။
(ဖြစ်နိုင်ရင်တော့ တနင်္ဂနွေနေ့မှာ မသွားတာ ပိုကောင်းပါလိမ့်မယ်။)
📝 Kodoba Note:
• 厚い (あつい - အာဆုအိ) = ထူသော • 上着 (うわぎ - ဥဝါဂိ) = အပေါ်အင်္ကျီ • 日曜日 (にちようび - နိချိယိုးဗိ) = တနင်္ဂနွေနေ့
第6課 いろいろなところに行けて、よかったです (နေရာအမျိုးမျိုးကို သွားနိုင်ခဲ့လို့ ဝမ်းသာပါတယ်)
❶ V-るつもりです
ရှင်းလင်းချက်: အနာဂတ်တွင် ပြုလုပ်ရန် ရည်ရွယ်ချက်/အစီအစဉ် ရှိကြောင်း ဖော်ပြခြင်း (ပြုလုပ်ရန် ရည်ရွယ်ထားသည်)။
例: 明日は、中禅寺湖に行くつもりです။
(မနက်ဖြန်တော့ ချူးဇဲန်ဂျိ ရေကန်ကို သွားဖို့ ရည်ရွယ်ထားပါတယ်။)
📝 Kodoba Note:
• 明日 (あした - အာရှိတာ) = မနက်ဖြန် • 湖 (みずうみ / こ - မိဇုဥမိ / ခို) = ရေကန်
❷ V-(られ)て、〜 / V-(られ)なくて、〜
ရှင်းလင်းချက်: Potential Form ၏ て Form ဖြင့် အကြောင်းပြချက်ကို ဆက်စပ်ပြီး ခံစားချက်ကို ဖော်ပြခြင်း (လုပ်နိုင်ခဲ့လို့/မလုပ်နိုင်ခဲ့လို့...)။
例①: いろいろなところに行けて、よかったです။
(နေရာအမျိုးမျိုးကို သွားနိုင်ခဲ့လို့ ဝမ်းသာရပါတယ်။)
例②: ショーが見られなくて、残念でした။
(ရှိုးပွဲ မကြည့်နိုင်ခဲ့လို့ နှမြောစရာပါပဲ။)
📝 Kodoba Note:
• よかった (ယောခတ်တ) = ကောင်းခဲ့သည်/ဝမ်းသာသည် • 残念 (ざんねん - ဇန်းနဲန်) = နှမြောစရာကောင်းသော/စိတ်မကောင်းသော
❸ S1 し、S2 し、〜
ရှင်းလင်းချက်: အကြောင်းပြချက် သို့မဟုတ် အချက်အလက်များစွာကို အစဉ်လိုက် ဆက်တိုက်ဖော်ပြခြင်း (〜လည်းဖြစ်ပြ၊ 〜လည်းဖြစ်လို့)။
例: 海で泳げたし、船に乗れたし、楽しかったです။
(ပင်လယ်မှာ ရေကူးနိုင်ခဲ့သလို၊ သင်္ဘောလည်း စီးနိုင်ခဲ့လို့ ပျော်စရာကောင်းခဲ့ပါတယ်။)
📝 Kodoba Note:
• 海 (うみ - ဥမိ) = ပင်လယ် • 泳ぐ (およぐ - အိုယိုးဂု) = ရေကူးသည် • 船 (ふね - ဖုနဲ) = သင်္ဘော • 乗る (のる - နောရု) = စီးသည်
❹ V-る / V-ている / V-た とき、〜
ရှင်းလင်းချက်: とき (အချိန်/တုန်းက) ဖြင့် လုပ်ဆောင်ချက်ဖြစ်ပွားသည့် အချိန်ကာလကို ညွှန်းဆိုခြင်း။
例: 道を歩いているとき、リスを見ました။
(လမ်းမှာ လမ်းလျှောက်နေတုန်း လှေကားထိုးရှဉ့်ကို တွေ့ခဲ့ပါတယ်။)
📝 Kodoba Note:
• 道 (みち - မိချိ) = လမ်း • 歩く (あるく - အာရုခု) = လမ်းလျှောက်သည် • リス (ရိဆု) = ရှဉ့်
❺ 【人】と【人数】で
ရှင်းလင်းချက်: မည်သူနှင့် မည်မျှအရေအတွက်ဖြင့် အတူတကွ သွားရောက်/ပြုလုပ်ခဲ့သည်ကို ဖော်ပြခြင်း။
例: 友だちと２人でハウステンボスに行って来ました။
(သူငယ်ချင်းနဲ့ ၂ ယောက်တည်း ဟောင်းစတဲန်ဘော့စ်ကို သွားခဲ့ပါတယ်။)
📝 Kodoba Note:
• 友だち (ともだち - တိုမိုဒါချိ) = သူငယ်ချင်း • ２人 (ふたり - ဖုတာရိ) = ၂ ယောက်
第7課 雨が降ったら、ホールでやりませす (မိုးရွာရင် ခန်းမမှာ လုပ်ပါမယ်)
❶ 〜たら、〜
ရှင်းလင်းချက်: အခြေအနေတစ်ရပ် ဖြစ်ပေါ်လာပါက (အကယ်၍ 〜 ဖြစ်လျှင်/ပြီးလျှင်) နောက်ဆက်တွဲ ပြုလုပ်မည်ကို ဖော်ပြခြင်း။
例: 雨が降ったら、盆踊りは日曜日にやるよ။
(မိုးရွာရင်တော့ ဘွန်းကပွဲကို တနင်္ဂနွေနေ့မှာ လုပ်မယ်နော်။)
📝 Kodoba Note:
• 雨 (あめ - အာမဲ) = မိုး • 降る (ふる - ဖုရု) = (မိုး/နှင်း) ရွာသည် • 盆踊り (ぼんおどり - ဘွန်းအိုဒိုရိ) = ဘွန်းပွဲတော် ကပွဲ
❷ V-(られ)ます ＜受身①＞
ရှင်းလင်းချက်: Passive Voice (ခံလိုပြ ကြိယာ) ကို သုံးစွဲ၍ အဖြစ်အပျက်/ပွဲလမ်းသဘင် ကျင်းပခြင်းကို ဖော်ပြခြင်း (ပြုလုပ်ခြင်းခံရသည်/ကျင်းပသည်)။
例: ７月14日、「ひかりホール」において、コンサートが開催されます။
(ဇူလိုင်လ ၁၄ ရက်နေ့မှာ "ဟိခါရီခန်းမ" မှာ ကွန်ဆာတ်ပွဲ ကျင်းပပြုလုပ်သွားပါမယ်။)
📝 Kodoba Note:
• ７月 (しちがつ - ရှိချိဂဆု) = ဇူလိုင်လ • 開催する (かいさいする - ခါအိဆာအိဆုရု) = ကျင်းပသည်
❸ V-(られ)ます ＜可能形②＞
ရှင်းလင်းချက်: Potential Form ဖြင့် မည်သူမဆို ပြုလုပ်နိုင်စွမ်းရှိကြောင်း ဖော်ပြခြင်း (ကနိုင်သည်/လုပ်နိုင်သည်)။
例: 盆踊りは簡単だから、誰でも踊れますよ။
(ဘွန်းကပွဲက လွယ်တာမို့ ဘယ်သူမဆို ကလို့ရပါတယ်နော်။)
📝 Kodoba Note:
• 簡単 (かんたん - ခန်းတန်း) = လွယ်ကူသော • 誰でも (だれでも - ဒါရဲဒဲမို) = မည်သူမဆို • 踊る (おどる - အိုဒိုရု) = ကနွဲ့သည်/ကသည်
第8課 屋台はどこかわかりますか？ (ဈေးဆိုင်တန်းက ဘယ်မှာလဲဆိုတာ သိပါသလား)
❶ もう V-ました / まだ V-て(い)ません
ရှင်းလင်းချက်:
• もう V-ました: ပြီးစီးသွားခဲ့ပြီလား
• まだ V-ていません: မပြီးသေးပါ/မလုပ်ရသေးပါ
A: スピーチコンテストは、もう始まりましたか？
(စကားပြောပြိုင်ပွဲက စနေပြီလား။)
B: まだ始まってません။
(မစရသေးပါဘူး။)
📝 Kodoba Note:
• スピーチコンテスト (ဆုပီးချိ ခွန်းထဲဆုတို) = စကားပြောပြိုင်ပွဲ • 始まる (はじまる - ဟာဂျိမာရု) = စသည်

📝 Kodoba Note:

❸ 【疑問詞】＋ S(普通形) か、〜
ရှင်းလင်းချက်: စာကြောင်းတစ်ခုအတွင်း အမေးစကားလုံးပါသော မေးခွန်းကို မြှုပ်နှံ၍ ပြောဆိုခြင်း (ဘယ်အချိန်လဲ ဆိုတာကို...)။

📝 Kodoba Note:
• フリーマーケット (ဖုရီး မာခဲတ်တို) = Flea Market / လွတ်လပ်သောစျေးရောင်းပွဲ • 何時 (なんじ - နန်းဂျိ) = ဘယ်နှနာရီ

例: 成人の日は、何をするんですか？
(လူပျို/အပျိုဖော်ဝင်ပွဲနေ့မှာ ဘာလုပ်ကြတာပါလဲ။)
📝 Kodoba Note:
• 成人の日 (せいじんのひ - ဆေးဂျင်းနိုဟိ) = အသက် ၂၀ ပြည့်/လူကြီးဖြစ်ခြင်း အထိမ်းအမှတ်နေ့

ရှင်းလင်းချက်: しか + အငြင်းစကားလုံး။ (N မှအပ/ N သာလျှင် ရှိသည်၊ ဒါပဲ ရသည်)။

(ကစားစရာ စီးတော်ယာဉ် ၃ ခုပဲ စီးနိုင်ခဲ့ပါတယ်။)
📝 Kodoba Note:
• 乗り物 (のりもの - နောရိမိုနို) = စီးတော်ယာဉ်/ကစားစရာ

ရှင်းလင်းချက်: အကန့်အသတ်ကို ဖော်ပြခြင်း (N သာလျှင်/ပဲ)။

(ဒီနှစ်တော့ ၁ ရက်ပဲ မိဘအိမ် ပြန်ဖြစ်ခဲ့ပါတယ်။)
📝 Kodoba Note:
• 今年 (ことし - ခိုတိုရှိ) = ဒီနှစ် • 実家 (じっか - ဂျိခ်ခါ) = မိဘအိမ်/ဇာတိအိမ်
❹ V-たりして、〜
ရှင်းလင်းချက်: ပြုလုပ်ခဲ့သော အကြောင်းအရာများကို ဥပမာအဖြစ် မြှုပ်နှံဖော်ပြခြင်း (ပြုလုပ်လိုက်၊ 〜လုပ်လိုက်နဲ့)။

📝 Kodoba Note:

ရှင်းလင်းချက်: Verb-なければならない ၏ စကားပြောစတိုင်ဖြစ်ပြီး မပြုလုပ်လျှင် မဖြစ်သောအရာကို ဖော်ပြခြင်း (မလုပ်လို့ မရဘူး/လုပ်ရမယ်)။

📝 Kodoba Note:

📝 Kodoba Note:

ရှင်းလင်းချက်: ပြုလုပ်ဆောင်ရွက်မှု နှစ်ခုကို တစ်ချိန်တည်း ပြိုင်တူ ပြုလုပ်ခြင်း (ပြုလုပ်ရင်းနဲ့)။

(ဖြစ်နိုင်ရင် အိတ် အခိုးခံလိုက်ရတာ ဖြစ်နိုင်ပါတယ်။)

第12課 この掃除機は軽くて動かしやすいですよ (ဒီဖုန်စုတ်စက်က ပေါ့ပါးပြီး ရွှေ့ရလွယ်ပါတယ်)
❶ V-るまで、〜
ရှင်းလင်းချက်: ပြုလုပ်ဆောင်ရွက်မှု သို့မဟုတ် အချိန်အတိုင်းအတာတစ်ခု ရောက်သည်အထိ (အထိ)။
例: 手元に届くまで、２日しかかりませんでした။
(လက်ဝယ်သို့ ရောက်ရှိသည်အထိ ၂ ရက်ပဲ ကြာခဲ့ပါတယ်။)
📝 Kodoba Note:
• 手元 (てもと - တဲမိုတို) = လက်ဝယ် • 届く (とどく - တိုဒိုးခု) = ရောက်ရှိသည်
❷ V-やすいです / V-にくいです
ရှင်းလင်းချက်:
• V-やすい: ပြုလုပ်ရ လွယ်ကူသည်
• V-にくい: ပြုလုပ်ရ ခက်ခဲသည်
例①: どちらが使いやすいですか？
(ဘယ်တစ်ခုက သုံးရတာ ပိုလွယ်ပါသလဲ။)
例②: この掃除機は、重くて、使いにくいですね။
(ဒီဖုန်စုတ်စက်က လေးပြီး သုံးရတာ ခက်တာပဲနော်။)
📝 Kodoba Note:
• 掃除機 (そうじき - ဆိုဂျိခိ) = ဖုန်စုတ်စက် • 使う (つかう - ဆုခါဥ) = သုံးစွဲသည် • 重い (おもい - အိုမိုးအိ) = လေးလံသော
❸ N1 と N2(と)、どちら / どっちが〜か？
ရှင်းလင်းချက်: နှိုင်းယှဉ်ချက် မေးခွန်းနှင့် ဖြေဆိုခြင်း ပုံစံ။
A: どっちが使いやすいですか？
(ဘယ်တစ်ခုက ပိုသုံးရတာ လွယ်သလဲ။)
B: シーバの掃除機のほうがスギタより軽くて、動かしやすいですよ။
(ရှီးဗား ဖုန်စုတ်စက်က စူဂိတာထက် ပိုပေါ့ပြီး ရွှေ့ရတာ လွယ်ပါတယ်နော်။)
📝 Kodoba Note:
• 軽い (かるい - ခါရုအိ) = ပေါ့ပါးသော • 動かす (うごかす - ဥဂိုးခါဆု) = ရွှေ့လျားသည်
第13課 いろいろな資料を展示してあります (စာရွက်စာတမ်း အချက်အလက်မျိုးစုံကို ပြသထားပါတယ်)
❶ V-(られ)ます ＜受身④＞
ရှင်းလင်းချက်: ဖြစ်ပျက်ခဲ့သော သမိုင်းဝင်/အဆောက်အဦးဆိုင်ရာ ဖြစ်စဉ်ကို Passive Voice ဖြင့် ဖော်ပြခြင်း။
例: この建物は、２年前に建てられました။
(ဒီအဆောက်အဦးကို လွန်ခဲ့တဲ့ ၂ နှစ်က ဆောက်လုပ်ခဲ့တာ ဖြစ်ပါတယ်။)
📝 Kodoba Note:
• 建物 (たてもの - တာတဲမိုနို) = အဆောက်အဦး • 建てられる (တါတဲရာရဲရု) = ဆောက်လုပ်ခြင်းခံရသည်
❷ V-てあります
ရှင်းလင်းချက်: ရည်ရွယ်ချက်ရှိရှိဖြင့် ပြုလုပ်ပြင်ဆင်ထားသော အခြေအနေ တည်ရှိနေခြင်း (ပြုလုပ်ထားရှိသည်)။
例: 昔、使われた道具とか、いろいろな資料を展示してあります။
(ရှေးက သုံးခဲ့တဲ့ ကိရိယာတွေနဲ့ စာရွက်စာတမ်းမျိုးစုံကို ပြသထားရှိပါတယ်။)
📝 Kodoba Note:
• 昔 (むかし - မုခါရှိ) = ရှေးယခင်က • 道具 (どうぐ - ဒိုးဂု) = ကိရိယာ/တန်ဆာပလာ • 展示する (てんじする - တဲန်ဂျိဆုရု) = ပြသသည်
❸ N1 だけじゃなくて、N2 も〜
ရှင်းလင်းချက်: N1 သာမက N2 လည်းပဲ အကျုံးဝင်ကြောင်း ဖော်ပြခြင်း။
例: 本だけじゃなくて、CDとか、DVDもただで借りられます။
(စာအုပ်တင်မကဘဲ CD တို့ DVD တို့လည်း အခမဲ့ ငှားရမ်းနိုင်ပါတယ်။)
📝 Kodoba Note:
• 本 (ほん - ဟွန်း) = စာအုပ် • ただ (တာဒါ) = အခမဲ့ • 借りる (かりる - ခါရိရု) = ငှားရမ်းသည်
❹ Nなら、〜
ရှင်းလင်းချက်: အခြေအနေ သို့မဟုတ် နေရာအလိုက် ကန့်သတ်အကြံပြုခြင်း (N ဆိုရင်တော့)။
例: 返却は、市内の図書館なら、どこに返してもいいです။
(စာအုပ်ပြန်အပ်တာကတော့ မြို့နယ်အတွင်းမှာရှိတဲ့ စာကြည့်တိုက်ဆိုရင် ဘယ်မှာပဲ ပြန်အပ်အပ် ရပါတယ်။)
📝 Kodoba Note:
• 返却 (へんきゃく - ဟဲန်ခယားခု) = ပြန်လည်အပ်နှံခြင်း • 図書館 (としょかん - တိုရှို့ခန်) = စာကြည့်တိုက်
❺ 【疑問詞】V-ても、〜
ရှင်းလင်းချက်: ဘာပဲလုပ်လုပ်/ဘယ်သူပဲဖြစ်ဖြစ် အဆင်ပြေကြောင်း ဖော်ပြခြင်း (ဘယ်... မဆို)။
例: 返却は、市内の図書館なら、どこに返してもいいです။
(ပြန်အပ်တာက မြို့နယ်ထဲက စာကြည့်တိုက်ဆို ဘယ်မှာပဲ ပြန်အပ်အပ် ရပါတယ်။)
第14課 前髪は、もう少し短く切ってもらえますか？ (ရှေ့ဆံပင်ကို နည်းနည်းလောက် ပိုတိုတို လှီးပေးလို့ရမလား)
❶ ナA-に / イA-く V
ရှင်းလင်းချက်: ဝိသေသနကို ကြိယာဝိသေသန (Adverb) ပြောင်း၍ ပြုလုပ်ဆောင်ရွက်မှုကို ဖော်ပြခြင်း (〜အောင်/စွာ ပြုလုပ်သည်)။
例: 全体的に短く切ってください။

📝 Kodoba Note:
• 全体的 (ぜんたいてき - ဇဲန်တိုက်တဲခိ) = တစ်ခေါင်းလုံး/ခြုံငုံ၍ • 短い (みじかい - မိဂျိခါအိ) → 短く (တိုတို) • 切る (きる - ခိရု) = ညှပ်သည်/လှီးသည်

(နိုင်ငံခြားသားတွေအတွက် ဝန်ဆောင်မှုမျိုးစုံ ရှိပါတယ်။)
📝 Kodoba Note:
• 外国 (がいこく - ဂါအိခိုခု) = နိုင်ငံခြား • サービス (ဆားဗိဆု) = ဝန်ဆောင်မှု
第15課 会議室の電気がついたままでした (အစည်းအဝေးခန်းရဲ့ မီးက လင်းထားလျက်တန်း ရှိနေခဲ့တယ်)
❶ V-たままです
ရှင်းလင်းချက်: အခြေအနေတစ်ခု ဖြစ်ပေါ်နေသည့်အတိုင်း ဆက်လက်ရှိနေခြင်း (အတိုင်း/လျက်တန်း)။
例: 会議室の電気がついたままでしたよ။
(အစည်းအဝေးခန်းမီးက လင်းထားတဲ့အတိုင်း ရှိနေခဲ့တယ်နော်။)
📝 Kodoba Note:
• 会議室 (かいぎしつ - ခါအိဂိရှိဆု) = အစည်းအဝေးခန်း • 電気 (でんき - ဒဲန်ခိ) = မီး/လျှပ်စစ် • つく (ဆုခု) = (မီး) လင်းသည်
❷ V-るのにおいいです
ရှင်းလင်းချက်: ရည်ရွယ်ချက်အတွက် ကောင်းမွန်ကြောင်း ဖော်ပြခြင်း (လုပ်ဖို့အတွက် ကောင်းသည်)။
例: マイストローは、ごみを減らすのにいいんですよ။
(ကိုယ်ပိုင် ပိုက်သုံးတာက အမှိုက်လျှော့ချဖို့အတွက် ကောင်းပါတယ်နော်။)
📝 Kodoba Note:
• ストロー (ဆုတိုရိုး) = ပိုက် • ごみ (ဂေါမိ) = အမှိုက် • 減らす (へらす - ဟဲရာဆု) = လျှော့ချသည်
第16課 地震が来ても、あわてて動かないでください (ငလျင်လှုပ်ရင်တောင် ပျာပျာသယာ ရွှေ့လျားခြင်း မလုပ်ပါနဲ့)
❶ V (命令形) / V-るな (禁止の命令形)
ရှင်းလင်းချက်: အမိန့်ပေးပုံစံနှင့် တားမြစ်မိန့် (လုပ်! / မလုပ်နဲ့!)။
例①: 急げ。こっちに集まれ။
(မြန်မြန်လုပ်။ ဒီဘက်ကို စုကြ။)
例②: 走るな။
(မပြေးနဲ့။)
📝 Kodoba Note:
• 急ぐ (いそぐ - အိဆိုဂု) = အလျင်လိုသည် • 集まる (あつまる - အာဆုမာရု) = စုဝေးသည် • 走る (はしる - ဟာရှိရု) = ပြေးသည်
❷ V-ないようにしてください
ရှင်းလင်းချက်: မပြုလုပ်မိစေရန် သတိထား ဆောင်ရွက်ခိုင်းခြင်း (မဖြစ်အောင် လုပ်ပါ။)
例: できるだけ煙を吸わないようにしてください။
(နိုင်သလောက် မီးခိုး မရှူမိအောင် လုပ်ပါ။)
📝 Kodoba Note:
• 煙 (けむり - ခဲမူရိ) = မီးခိုး • 吸う (すう - ဆူး) = ရှူသွင်းသည်
❸ V-(られ)なくなります
ရှင်းလင်းချက်: ပြုလုပ်နိုင်စွမ်း မရှိတော့သည့် အခြေအနေသို့ ပြောင်းလဲသွားခြင်း (မလုပ်နိုင်တော့ပါ)။
例: ドアが開かなくなると、外に逃げられなくなります။
(တံခါး ဖွင့်လို့မရတော့ရင် အပြင်ကို မပြေးနိုင်တော့ပါဘူး။)
📝 Kodoba Note:
• ドア (ဒိုးအာ) = တံခါး • 開く (あく - အာခု) = ပွင့်သည် • 逃げる (にげる - နိဂဲရု) = ထွက်ပြေးသည်
❹ Sても、〜
ရှင်းလင်းချက်: သော်လည်း/ ဖြစ်လင့်ကစား (အကယ်၍ ဖြစ်ခဲ့ရင်တောင်)။
例: 大きな地震が来ても、あわてて動かないでください။
(ငလျင်ကြီး လှုပ်ခဲ့ရင်တောင် ပျာပျာသယာ ရွှေ့လျားခြင်း မလုပ်ပါနဲ့။)
📝 Kodoba Note:
• 地震 (じしん - ဂျိရှိန်) = ငလျင် • あわてる (အာဝါတဲရု) = ပျာပျာသယာဖြစ်သည်
❺ V(普通形) かどうか、〜
ရှင်းလင်းချက်: ဟုတ်မဟုတ်/ ဖြစ်မဖြစ်ကို ဖော်ပြခြင်း။
例: 店が開いているかどうか、わからないけど…။
(ဆိုင် ဖွင့်ထားလား မဖွင့်ထားဘူးလား မသိပေမဲ့...)
第17課 日本語が前より話せるようになりました (ဂျပန်ဘာသာစကားကို အရင်ကထက် ပိုပြောနိုင်လာခဲ့ပါတယ်)
❶ V-(られ)るようになりました
ရှင်းလင်းချက်: မပြုလုပ်နိုင်ခဲ့ရာမှ လေ့ကျင့်မှုကြောင့် ပြုလုပ်နိုင်သည့် အခြေအနေသို့ ပြောင်းလဲလာခြင်း (တတ်မြောက်လာခဲ့သည်/ပြုလုပ်နိုင်လာခဲ့သည်)။
例: 最近は、ほかの人にお店の情報を教えられるようになりました။

📝 Kodoba Note:

❶ V-(よ)うと思います / 思っています
ရှင်းလင်းချက်: Volitional Form ကိုသုံး၍ အနာဂတ် ရည်မှန်းချက်ကို ဖော်ပြခြင်း (ပြုလုပ်မည်ဟု စိတ်ကူး/တွေးထားသည်)။
例: 将来は、タイで、自分の会社を作ろうと思います။
(အနာဂတ်မှာ ထိုင်းမှာ ကိုယ်ပိုင်ကုမ္ပဏီ ထောင်မယ်လို့ တွေးထားပါတယ်။)
📝 Kodoba Note:
• 将来 (しょうらい - ရှိုးရိုးအိ) = အနာဂတ် • 会社 (かいしゃ - ခါအိရှာ) = ကုမ္ပဏီ • 作る (つくる - ဆုခုရု) = ပြုလုပ်/ထောင်သည်
❷ V-るために、〜
ရှင်းလင်းချက်: ရည်ရွယ်ချက်အတွက် (ပြုလုပ်ရန်အတွက်)။
例: 日本に住むために、もっと日本語をがんばろうと思います။
(ဂျပန်မှာ နေထိုင်ဖို့အတွက် ဂျပန်စာကို ပိုပြီး ကြိုးစားမယ်လို့ တွေးထားပါတယ်။)
📝 Kodoba Note:
• 住む (すむ - ဆုမု) = နေထိုင်သည်
❸ V-てあげる / V-てもらう / V-てくれる
ရှင်းလင်းချက်: ကူညီပေးကမ်းမှု အပြန်အလှန် ပြုလုပ်ပေးခြင်း ပုံစံများ။
• V-てあげる: ပြုလုပ်ပေးသည်
• V-てもらう: ပြုလုပ်ပေးခြင်း ခံရသည်/အကူအညီ ရယူသည်
• V-てくれる: မိမိအား ပြုလုပ်ပေးသည်
例①: 両親に、家を建ててあげるつもりです။
(မိဘတွေကို အိမ် ဆောက်ပေးဖို့ ရည်ရွယ်ထားပါတယ်။)
例②: JF工業のみなさんには、とても親切にしてもらいました။
(JF စက်မှုဇုန်က လူတွေဆီက စေတနာထား ကူညီပေးတာကို ခံခဲ့ရပါတယ်။)
例③: 山内さんは、私にたくさん、日本語を教えてくれました။
(ယားမားအုချိစံက ကျွန်တော့်ကို ဂျပန်စာ အများကြီး သင်ပေးခဲ့ပါတယ်။)
📝 Kodoba Note:
• 両親 (りょうしん - ရိုးရှိန်) = မိဘနှစ်ပါး • 家 (いえ - အိအဲ) = အိမ် • 親切 (しんせつ - ရှိန်းဆဲဆု) = ကြင်နာသော/စေတနာရှိသော
